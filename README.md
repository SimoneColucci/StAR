# StAR – Statistical Analysis of Rocks

A new user-friendly tool for routine rock characterisation. 
StAR enables users to 
i)  statistically characterise particle (e.g., bubbles, crystals, clasts) size distributions using a robust and well-established fitting procedure; 
ii) determine the fractal index of the distribution
ii) convert 2D data to 3D applying stereological methods; 
iii) visualise particle shape and orientation distributions.

The statistical part of *Properties* is based on:
> Proussevitch A.A., Sahagian D.L., Tsentalovich E.P. (2007)
> *Statistical analysis of bubble and crystal size distributions*,
> JVGR, 164(3), 95-111.

StAR enables users to develop an analytical workflow either through a graphical user interface or directly via Python scripts. 

StAR includes four modules, exposed in a single tabbed GUI (Tkinter):

    PreProcess  →  Analyze  →  Stereology  →  Properties

Each module can be used **independently** or **in succession** within a single
workflow. When modules are run in succession, the fields of the downstream
tabs are filled in automatically (they remain fully editable).

## Workflow

1. **PreProcess** – spatial calibration of the input image file; cropping a region of the image; calculation of the intensity threshold for image binarisation.
   Groups are defined here and shared with all downstream tabs.
   Particle-size data from images belonging to the same group are pooled during the statistical analysis.
   This is useful for images from the same sample acquired at different magnifications.
   Saves the results in `<output>/preProcessingResults.csv` and the cropped images in `<output>/CropImages`. 
3. **Analyze** – `Group / File` auto-filled with `<output>/CropImages/<myfile>.jpg` after PreProcess;
   the `m/pixel` values and the `Int. min` and `Int. max` read from `preProcessingResults.csv`.
   Generates `<output>/Measurements/measurementsTable_XXX.csv` and property
   histograms and orientation rose diagrams in `<output>/Measurements/Figures/`.
5. **Stereology** *(optional)* – `Group / File` auto-filled with the `measurementsTable_XXX`
   files generated by Analyze. Produces `measurementsStereoTable_XXX.csv` and
   comparison figures.
6. **Properties** – `Group / File` auto-filled with the `measurementsTable_XXX` files (or the
   `measurementsStereoTable_XXX.csv` files after Stereology is run);
   `m/pixel` and `cropArea` are read from `preProcessingResults.csv`.
   Saves best-fitting parameters in `<output>/Statistics/DensityBasedFitting_*.csv` and `<output>/Statistics/ExceedanceBasedFitting_*.csv`
   and calculated properties in `<output>/Statistics/Properties_*.csv`.    
   Optionally computes the fractal index and saving results in `<output>/Statistics/FractalIndex_*.csv`.
   Saves figures with the results of the fitting and the fractal analysis.

## Requirements

- Python ≥ 3.8
- numpy ≥ 1.21
- scipy ≥ 1.7
- matplotlib ≥ 3.5
- pandas ≥ 1.3
- scikit-image ≥ 0.19
- Pillow ≥ 9.0
- pyinstaller ≥ 5.0


```bash
pip install -r requirements.txt
```

The **Stereology** module additionally requires the `pysizeunfolder` package
(from GitHub):

```bash
pip install git+https://github.com/thomasvdj/pysizeunfolder
```

## Usage

### Unified tabbed GUI (recommended)

```bash
python star_gui.py
```

The window has a shared **output folder** at the top and four tabs (PreProcess,
Analyze, Stereology, Properties). The interactive operations of PreProcess
(calibration, cropping, intensity range) open a window with the image where you
click/select. After each module completes, the downstream tabs are filled in
automatically.

Groups are defined once in the PreProcess tab and inherited by all other tabs.
Each tab shows the same group/file tree and edits the same shared data model.


### Command line (individual modules)

Edit the parameters in the scripts and run them from the `run` folder:

```bash
cd run
python preprocess.py    # PreProcess (interactive matplotlib windows)
python analyze.py       # Analyze
python stereology.py    # Stereology
python properties.py    # Properties
```

## Building a standalone executable

PyInstaller creates a distributable package that **does not require Python** on
the end user's machine.

### Windows (.exe)

1. Copy the entire `StAR` folder to the Windows PC (with Python 3.9+ installed)
2. Double-click `build_windows.bat`
3. The executable will be created in `dist/StAR/StAR.exe`

### Linux

1. Make sure you have Python 3.9+ and pip
2. Run:

```bash
chmod +x build_linux.sh
./build_linux.sh
```

3. The executable will be created in `dist/StAR/StAR`

### Manually (any OS)

```bash
pip install pyinstaller
pyinstaller StAR.spec --noconfirm
```

The resulting `dist/StAR/` folder can be distributed (or zipped) as is.

## Structure

```
python/
├── star_gui.py                     ← unified tabbed GUI (entry point)
├── gui.py                          ← old GUI (Properties only)
├── run/
│   ├── preprocess.py               ← CLI PreProcess
│   ├── analyze.py                  ← CLI Analyze
│   ├── stereology.py               ← CLI Stereology
│   └── properties.py               ← CLI Properties
├── src/
│   ├── run_preprocessing.py        ← PreProcess pipeline
│   ├── run_analyze.py              ← Analyze pipeline
│   ├── run_stereology.py           ← Stereology pipeline
│   ├── run_bubble_properties.py    ← Properties pipeline
│   ├── preprocessing/
│   │   ├── preprocessing.py        ← logic (calibration/crop/intensity)
│   │   └── interactive_mpl.py      ← matplotlib interactors (CLI)
│   ├── analyze/
│   │   ├── analyze_bubble.py       ← segmentation + regionprops
│   │   └── property_figures.py     ← per-group histograms + rose diagrams
│   ├── stereology/
│   │   ├── stereology.py
│   │   ├── convert_measurement.py
│   │   └── size_estimation_unit_radius.py
│   └── bubble_properties/
│       ├── bubble_properties.py    ← analysis orchestrator
│       ├── check_input.py          ← input validation
│       ├── fractal_index.py        ← fractal index (Otsuki, 1998)
│       └── statistics/             ← distributions, fitting, solver
├── data/                           ← example data (Images, CropImages, Measurements)
├── output/                         ← results (created automatically)
├── requirements.txt
├── StAR.spec                       ← PyInstaller configuration
├── build_windows.bat               ← Windows build script
└── build_linux.sh                  ← Linux build script
```

## Output

- **PNG** – distribution plots (density + exceedance), χ², parameters,
  per-group property histograms, orientation rose diagrams, fractal index
- **CSV** – measurement tables, stereology tables, fitting parameter tables,
  fractal index values

## Input data format

`.csv` files with at least the `EquivDiameter` column.
